# Code Provenance

## Copyright Notice

The International Building Code (IBC) is developed and copyrighted by the
International Code Council (ICC). The ADA Standards for Accessible Design
are maintained by the U.S. Access Board and the Department of Justice.

This benchmark stores **only section identifiers** (e.g., "IBC 2024 §1020.2")
and **functional paraphrases** of dimensional requirements. No copyrighted
code text, commentary, figures, or tables are reproduced.

## Legal Guidance

The Supreme Court's government-edicts doctrine (*Georgia v. Public.Resource.Org, Inc.*, 2020)
covers works authored by government officials. However, model codes authored by private
organizations (ICC) may retain copyright even when adopted by jurisdictions.

This project's approach (section identifiers + functional paraphrases + executable predicates)
is designed to respect copyright while enabling reproducible research.
